title: nandex (Forge41)
---

nandex is an open-source RAG system by Forge41: connect third-party apps via a credential broker (tps), import their data (Temporal workflows), ingest (parse → chunk → embed → index with pgvector), retrieve with hybrid search fused by Reciprocal Rank Fusion and cross-encoder reranking, and chat with streamed, structured citations. It also hosts an AI interview room: a LiveKit agent runs a resume-derived plan with sandboxed coding and SQL rounds.
